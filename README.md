# 自动化 Skills 学习

把**已完成工具任务里的可观察经验**整理成可复用的 `SKILL.md`：学习后可搜索、审阅、编辑、保留历史版本，并在需要时发布到 AstrBot 原生技能库。它是可审核的经验整理，不是模型训练，也不代表技能已在其他环境验证成功。

当前版本：**v1.3.0** · 需要 AstrBot **4.28.1+** / Python **3.10+**

## 快速开始

1. 安装插件并加载后，登录现有 AstrBot Dashboard。
2. 在左侧「插件 WebUI」打开 **自动化skills学习**；也可使用 `/技能管理` 查看管理入口。插件不启动额外 Web 服务或监听端口。
3. 普通用户可用 `/技能列表`、`/技能搜索 <关键词>`、`/技能查看 <名称>`、`/技能统计`；管理操作只允许 AstrBot 管理员执行。
4. 默认开启学习、全局共享和**人工审核**。到管理页检查候选、适用条件和工具证据，确认后再批准；如需发布给 AstrBot 原生 SkillManager，再选择「批准并发布」。

## 学到什么、怎样学习

插件从**当前 Agent 轮次**的工具公开结果和最终公开总结中提取可复用步骤。不读取聊天历史、隐藏思维、工具输入参数或凭据文件；任务未完成、工具全失败、缺少结果或证据不足时不生成技能。成功内容仍可能有错，技能是参考资料，使用前要核对环境、权限和工具回执。

自动生成默认进入待审核区，不会立即被普通技能检索使用。检索先给出已批准技能的名称和用途；确认适用后加载正文才计一次使用。搜索本身、浏览管理页和发布不会增加使用次数。若证据不足，模型可返回 `null`，表示没有可保存的技能，不代表插件保存故障。

## 主要功能

- **结构化任务经验**：步骤、检查项、注意事项，以及适用条件、真实工具名、工作流和标签；中文描述，机器标识保留原名。
- **保守去重与合并**：按用途、适用条件、流程和工具证据匹配；有歧义或多个候选时宁可分开，不靠共享的“找文件”等步骤猜测任务相同。重复经验更新证据而不制造无意义的新版本。
- **审核、版本与回滚**：人工审核默认开启；保留历史版本，可把历史恢复为一个新的待审核版本。页面提供搜索、标签分类、编辑、删除、批准、拒绝、发布和统计。
- **可选的 AstrBot 原生发布**：只发布插件自己创建且完整性校验通过的文件；不覆盖手工技能或被人工改过的发布副本。隔离数据不发布。
- **全局或按用户隔离**：默认共享库；可切换按会话和用户隔离，已有隔离与共享数据不会互相搬运。隔离模式不会由无会话身份的 Dashboard 页面列出其他用户的数据。
- **到期清理与使用统计**：显示技能累计加载次数和最近使用；生成技能超过 30 天未使用会按规则清理，旧记录有观察期，手工技能及被人工改动的原生文件不会自动删除。
- **Dashboard 原生管理页**：沿用现有登录认证，不另开端口、不依赖 CDN。写操作检查身份、来源和 CSRF；窄屏可上下浏览。

## 常用命令

```text
/技能列表
/技能搜索 文档校验
/技能查看 verify-document
/技能统计
```

仅管理员可执行审核、编辑、回滚、发布和开关操作，例如：

```text
/技能审核 verify-document 批准
/技能审核 verify-document 批准发布
/技能回滚 verify-document 1
/技能管理
```

## 使用成本与安全边界

- 每次符合条件的学习尝试最多额外调用一次总结模型，可能产生模型费用；搜索、合并、审核、管理页和发布不调用模型。
- 默认每个学习作用域冷却 10 分钟；繁忙时跳过，不排队补学旧任务。容量默认 100 项，满时仍可尝试合并已有技能。
- 对常见凭据格式命中即拒绝，URL、邮箱、路径和长标识会脱敏；这不是通用 DLP，无法保证识别所有私人自然语言，敏感任务可关闭自动学习。
- 自动发布审核模式是可选设置，有误发布风险；默认人工审核更稳妥。批准仅表示管理员接受候选，不代表真实测试过。
- Dashboard 沿用自身网络暴露范围，请将管理入口限制在可信网络并妥善保护 Dashboard 管理账号。
