# astrbot_plugin_task_skills - 自动化 Skills 学习

**版本**: v1.1.1  
**大小**: ~75 KB  
**功能**: 结构化任务技能库，支持保守合并、版本回滚、原生发布和认证管理

## 🌟 核心功能
- **技能学习**: 将工具任务经验保存为可检索、可编辑的结构化技能
- **版本管理**: 支持历史版本回滚、审核发布
- **认证管理**: 基于 AstrBot dashboard 的认证机制
- **共享库**: 默认共享的技能库，支持多用户协作

## 🚀 快速安装
1. 解压 ZIP 到 `AstrBot/data/plugins/astrbot_plugin_task_skills/`
2. 重启 AstrBot
3. Web UI 左侧点击"自动化 skills 学习"
4. 或使用 `/技能管理` 命令访问

## 📝 使用指令
```
/技能列表 | /技能查看 <名称> | /技能搜索 <关键词> | /技能统计
```
